# Lead Check

Веб-приложение для проверки JSON с данными лида. Оно помогает привести заявку к читаемому виду и проверить её перед дальнейшей обработкой.

## Как пользоваться

1. Вставьте JSON в поле `INPUT.JSON` или нажмите «Загрузить пример».
2. При необходимости нажмите «Форматировать».
3. Исправьте ошибки, если статус поля — `INVALID`.
4. Нажмите «Проверить лид». Приложение повторно проверит данные на сервере и покажет результат.

Для проверки нужны `lead_id` — положительное целое число, а также непустые строки `name` и `company_name`. Остальные поля необязательны; дополнительные поля заявки сохраняются.

## Запуск

Требуется Node.js и npm.

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## API

`POST /api/analyze` принимает JSON лида. Для корректных данных возвращает `200` и идентификатор лида. Для неверного JSON возвращает `400`, для неподходящих данных лида — `422` с описанием ошибки.

## Проверки проекта

```bash
npm run lint
npm run build
```

Приложение не отправляет данные в CRM.
