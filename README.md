# Lead Check

Веб-приложение для проверки и оценки лидов Worrki. Принимает JSON заявки, ищет публичные сведения о человеке и компании, показывает квалификацию лида и источники.

## Как пользоваться

1. Вставьте JSON в поле `INPUT.JSON` или нажмите «Загрузить пример».
2. При необходимости нажмите «Форматировать».
3. Исправьте ошибки, если статус поля — `INVALID`.
4. Нажмите «Проверить лид». Приложение проверит данные на сервере, выполнит поиск публичных источников и покажет результат анализа.

Для проверки нужны `lead_id` — положительное целое число, а также непустые строки `name` и `company_name`. Остальные поля необязательны; дополнительные поля заявки сохраняются.

В результате отдельно показаны `score` — интерес лида для Worrki — и `verification confidence` — насколько сведения подтверждены публичными источниками. Каждая проверка помечена как подтверждённая, неподтверждённая или не имеющая найденного публичного подтверждения. Ссылки на источники открываются из отчёта.

## Запуск

Требуются Node.js, npm и ключ OpenAI API. Создайте `.env.local` в корне проекта:

```env
OPENAI_API_KEY=your_api_key
```

Файл `.env.local` исключён из Git. Ключ используется только серверным маршрутом.

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## API

`POST /api/analyze` принимает JSON лида. Для корректных данных возвращает `200` с идентификатором лида и структурированным результатом анализа. Для неверного JSON возвращает `400`, для неподходящих данных лида — `422`, при ошибке анализа — `502`.
