# Lead Check

Приложение для проверки JSON лида перед AI-анализом и подготовкой результата для CRM.

Реализованы ввод JSON, форматирование, пример и проверка обязательных полей в интерфейсе и на сервере. `POST /api/analyze` принимает валидный лид и подтверждает его проверку. OpenAI-анализ и предпросмотр CRM OUTPUT пока не подключены. Реальная CRM-интеграция не планируется.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Проверки

```bash
npm run lint
npm run build
```

Перед подключением OpenAI потребуется создать `.env.local` с `OPENAI_API_KEY`; ключ будет использоваться только на сервере.
