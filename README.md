# Lead Check

Небольшое демо для проверки JSON лида перед AI-анализом и подготовкой результата для CRM.

Сейчас реализована первая итерация: ввод JSON, форматирование, пример и проверка обязательных полей. Вызов OpenAI и предпросмотр CRM OUTPUT будут добавлены в следующих итерациях. Реальная CRM-интеграция в тестовом не планируется.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Проверки

```bash
npm run lint
npm run build
```

Перед подключением OpenAI потребуется создать `.env.local` с `OPENAI_API_KEY`; ключ будет использоваться только на сервере.
