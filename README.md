# Lead Check

Небольшое демо для проверки JSON лида перед AI-анализом и подготовкой результата для CRM.

Сейчас реализованы ввод JSON, форматирование, пример и проверка обязательных полей в интерфейсе и на сервере. `POST /api/analyze` принимает валидный лид и подтверждает его проверку. Вызов OpenAI и предпросмотр CRM OUTPUT будут добавлены в следующих итерациях. Реальная CRM-интеграция в тестовом не планируется.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Проверки

```bash
npm run lint
npm run build
```

Перед подключением OpenAI потребуется создать `.env.local` с `OPENAI_API_KEY`; ключ будет использоваться только на сервере.
